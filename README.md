# My take on Starbie!
For week 1 of Hack Club Half Life, I followed the provided guide to build (and put my own spin on) Starbie. This version is designed with a space theme, with the silkscreen (graphics) and board shape based on Gargantua (the supermassive black hole in Interstellar).<br>
This current version only implements the basic electronics given in the guide, but the next revision will replace the DHT with a clock module to approximate corrections to time dilation.
